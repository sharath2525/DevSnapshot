# Privacy

DevSnapshot is fully local and offline.

It does not contain telemetry, analytics, advertising, accounts, cloud sync,
network requests, or an update checker. Project files are read only to create a
ZIP in the destination selected by the user. File contents are not written to
settings or logs.

Local application data:

- Settings: `%APPDATA%\DevSnapshot\config.json`
- Logs: `%APPDATA%\DevSnapshot\logs\devsnapshot.log`

Logs may include paths and filenames needed for troubleshooting, but not file
contents, environment-variable values, passwords, or API keys.
