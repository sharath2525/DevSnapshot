# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use the repository's
GitHub **Security > Report a vulnerability** form (private security advisory).
Include the affected version, reproduction steps, potential impact, and any
suggested remediation.

DevSnapshot handles local project data. Reports involving path traversal,
archive integrity, unintended file modification, secret exposure, symlink
handling, or unsafe installer behavior are treated as high priority.
